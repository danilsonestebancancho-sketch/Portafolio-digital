Guía Paso a Paso para Desplegar en GitHub Pages

  1. Crear el Repositorio en GitHub:

    Crea un repositorio público llamado upla-trabajos-universitarios. Sube este archivo renombrado a index.html.

  2. Crear Proyecto en Firebase Console:

    Ingresa a Firebase Console, crea un proyecto y habilita:

      /> Authentication (Email/Contraseña y Anónimo)
    • Cloud Firestore Database (Modo producción)
    • Firebase Storage
  3. Reglas de Seguridad Firestore (Copiar y Pegar): 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
  4. Activar GitHub Pages:

    En tu repositorio de GitHub, ve a Settings > Pages > Branch (main) > Save. ¡Tu sitio estará en vivo en pocos minutos!
